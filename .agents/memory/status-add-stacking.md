---
name: 상태부여 누적/덮어쓰기 규칙
description: addStatusToCharacter의 stackMode/maxValue/공란 횟수 처리 계약. 회귀 방지용.
---

같은 대상+상태명의 ACTIVE 행이 있을 때 동작:

- `stackMode = "허용"` (기본) → 기존 수치/횟수에 옵션값을 더한다.
- `stackMode ∈ {덮어쓰기, 불가, 갱신, 교체}` → 옵션값으로 덮어쓴다.
- 최대 캡: 옵션 `최대|최대값|최대치` > 0이면 그 값을, 아니면 기존 행의 `최대값|최대치` 열을 사용. 캡이 있으면 수치와 횟수 모두 클램프.
- `남은횟수`는 옵션 `횟수`가 명시 입력됐을 때만 셀에 쓴다. 미지정이면 기존 공란을 그대로 둔다(공란 = 무제한 의미 보존).
- STATUS_DB에 `최대값/최대치` 헤더가 없어도 안전해야 한다. `appendRowByHeaders`가 미존재 키를 무시하고, `setStatusCell`은 헤더 인덱스 -1이면 false 반환.

**Why:** 횟수 공란은 "무제한"을 뜻하는 기존 컨벤션. 갱신 시 0으로 강제 덮어쓰면 모든 상태가 1회 소진형으로 회귀한다. 캡은 옵션 우선이지만 기존 행에 저장된 캡도 후속 누적에서 살려야 함.

**How to apply:** 새 호출부를 추가할 때 `maxValue: _pickMaxOption(opts)`를 반드시 전달. 새 stackMode 키워드를 받으려면 `_isOverwriteStackMode`에 추가. 응답 헤더는 신규=`[상태 부여]`, 누적=`[상태 누적 갱신]`, 덮어쓰기=`[상태 갱신]`.
