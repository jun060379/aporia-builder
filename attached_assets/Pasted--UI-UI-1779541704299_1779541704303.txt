스킬 메이커의 계산식/효과 블럭 UI를 더 직관적으로 개선해줘.

중요:
- 기존 캐릭터 빌더, 포인트 계산, 액션 계산 로직은 건드리지 말 것.
- 스킬 메이커 관련 UI와 상태 관리만 수정할 것.
- 계통 선택지에서 "초능력", "과학"은 제거할 것.
- 계통 선택지는 다음만 사용:
  마술, 주술, 신성, 혈계, 요력, 특수

목표:
현재는 버튼을 누르면 토큰이 바로 들어가는 방식인데, 이러면 플레이어가 각 블럭이 뭘 참조하는지 알기 어렵다.
따라서 블럭 버튼을 누르면 팝업/모달이 뜨고, 그 안에서 필요한 값을 입력한 뒤 삽입하게 바꿔줘.

구현 방식:
1. 계산식 블럭 선택 버튼을 누르면 FormulaBlockModal을 열 것.
2. 효과 블럭 선택 버튼을 누르면 EffectBlockModal을 열 것.
3. 모달 상단에는 이 블럭이 무엇을 참조하는지 설명을 표시할 것.
4. 모달 중간에는 블럭이 요구하는 입력값을 표시할 것.
5. 모달 하단에는 생성 결과 미리보기를 표시할 것.
6. "삽입" 버튼을 누르면 계산식 또는 현재 효과 카드에 해당 텍스트를 추가할 것.
7. "취소" 버튼을 누르면 닫을 것.
8. 모바일에서는 모달이 화면 밖으로 나가지 않게 max-height와 overflow-auto를 적용할 것.

계산식 블럭 카테고리:

[기본]
- d6
  설명: 1d6 판정을 계산식에 추가합니다. 기대값 프리뷰에서는 3.5로 계산됩니다.
  생성: d6

- d20
  설명: 1d20 판정을 계산식에 추가합니다. 기대값 프리뷰에서는 10.5로 계산됩니다.
  생성: d20

- 2d6
  설명: 2d6 판정을 계산식에 추가합니다. 기대값 프리뷰에서는 7로 계산됩니다.
  생성: 2d6

- 랭크
  설명: 현재 스킬의 랭크값을 참조합니다. F=1, E=10, D=20, C=30, B=40, A=50, S=70, U=80, EX=100입니다.
  생성: 랭크

[스탯 참조]
- 스탯
  설명: 현재 캐릭터의 스탯 내부값을 참조합니다. 예를 들어 감각 A는 30으로 계산됩니다.
  입력값:
    스탯 선택: 근력 / 민첩 / 내구 / 감각 / 지능
  생성:
    선택한 스탯명

[기능 참조]
- 기능
  설명: 현재 캐릭터의 기능 수치를 참조합니다. 기능은 0~5 사이의 값입니다.
  입력값:
    기능 선택:
    무기술, 격투술, 사격술, 기동술, 방어술, 인내, 관찰, 추적술, 은밀행동, 지식, 이면학, 화술
  생성:
    선택한 기능명

[숙련 참조]
- 숙련
  설명: 현재 캐릭터의 숙련 수치를 참조합니다. 숙련은 0~5 사이의 값입니다.
  입력값:
    숙련 선택:
    참격숙련, 관통숙련, 타격숙련, 격투숙련, 사격숙련, 회피숙련, 방어숙련, 저항숙련, 조사숙련, 해석숙련, 은신숙련, 추적숙련, 설득숙련
  생성:
    선택한 숙련명

[자신의 상태 참조]
- 자신의 상태
  설명:
    스킬 사용자 자신에게 현재 걸려 있는 ACTIVE 상태를 참조합니다.
    상태_출혈_수치는 자신에게 걸린 출혈 상태들의 수치 합계를 의미합니다.
    상태_출혈_개수는 자신에게 걸린 출혈 상태의 개수를 의미합니다.
    상태_출혈_최대는 자신에게 걸린 출혈 상태 중 가장 높은 수치를 의미합니다.
    상태_출혈_존재는 출혈이 하나라도 있으면 1, 없으면 0입니다.
    상태_출혈_확률은 출혈 상태 중 가장 높은 확률값을 의미합니다.
  입력값:
    상태명: 직접 입력
    참조값: 수치 / 개수 / 최대 / 존재 / 확률
  생성:
    상태_[상태명]_[참조값]
  예시:
    상태_출혈_수치

[대상의 상태 참조]
- 대상의 상태
  설명:
    스킬의 대상에게 현재 걸려 있는 ACTIVE 상태를 참조합니다.
    대상 지정이 필요한 스킬에서만 정상적으로 사용할 수 있습니다.
    대상상태_출혈_수치는 대상에게 걸린 출혈 상태들의 수치 합계를 의미합니다.
    대상상태_구속_존재는 대상에게 구속이 있으면 1, 없으면 0입니다.
  입력값:
    상태명: 직접 입력
    참조값: 수치 / 개수 / 최대 / 존재 / 확률
  생성:
    대상상태_[상태명]_[참조값]
  예시:
    대상상태_출혈_수치
  주의:
    이 블럭을 사용하면 조건 칸에 "대상 지정 필요"를 추천하거나 경고로 표시할 것.

    스택_[스택명]

- 대상의 스택

  입력값:

  생성:

효과 블럭 카테고리:

[상태 템플릿 부여]
- 상태 템플릿 부여
  설명:
    미리 정의된 상태 템플릿을 자신 또는 대상에게 부여합니다.
    출혈, 구속, 보호막, 취약 같은 자주 쓰는 효과를 만들 때 사용합니다.
  입력값:
    대상: 대상 / 자신

    직접입력 템플릿명
    수치
    횟수
    최대
    저항 여부: 없음 / 가능
    저항난이도: 최종값 / 직접입력
  생성 형식:
    상태템플릿부여 [대상] [템플릿명] 수치:[수치] 횟수:[횟수] 최대:[최대] 저항:가능 저항난이도:[저항난이도]
  예시:
    상태템플릿부여 대상 출혈 수치:5 횟수:3
    상태템플릿부여 대상 구속 저항:가능 저항난이도:최종값
    상태템플릿부여 자신 보호막 수치:20

  입력값:

    효과코드: bleed / bind / shield / vulnerable / weaken / buff / 직접입력
    수치
    확률
    횟수
    발동
    판정
    중복
    저항 여부
    저항난이도
    메모
  생성 형식:
    상태부여 [대상] [상태명] [분류] [효과코드] 수치:[수치] 확률:[확률] 횟수:[횟수] 발동:[발동] 판정:[판정] 중복:[중복] 저항:가능 저항난이도:[저항난이도] 메모:[메모]
  예시:
    상태부여 대상 화상 지속피해 burn 수치:5 확률:100 횟수:3 발동:판정시작 판정:액션,스킬 중복:허용

[상태 해제]
- 상태 해제
  설명:

  입력값:
    대상: 대상 / 자신

  생성:

  예시:

    상태해제 대상 구속

[스택 변경]
- 스택 변경
  설명:
    자신 또는 대상의 스택을 증가, 감소, 설정합니다.
    스택은 이후 계산식에서 스택_혈인 또는 대상스택_표식처럼 참조할 수 있습니다.
  입력값:
    변경 종류: 증가 / 감소 / 설정
    대상: 자신 / 대상
    스택명
    값
    최대
  생성 형식:
    증가: 스택증가 [대상] [스택명] +[값] 최대:[최대]
    감소: 스택감소 [대상] [스택명] -[값]
    설정: 스택설정 [대상] [스택명] =[값] 최대:[최대]
  예시:
    스택증가 자신 혈인 +1 최대:10
    스택감소 자신 혈인 -1
    스택설정 대상 표식 =3 최대:5

[자유 입력]
- 자유 입력
  설명:
    자동 생성 블럭으로 만들 수 없는 효과를 직접 입력합니다.
    이 효과는 운영진 수동 검수 대상입니다.
  입력값:
    직접 입력 textarea
  생성:
    입력한 텍스트 그대로 사용

효과 카드 UI:
- 효과는 하나의 textarea가 아니라 effects 배열로 관리할 것.
- 각 효과 카드는 하나의 줄 효과를 생성한다.
- 효과 카드마다 "블럭 선택" 버튼을 둔다.
- 블럭 선택을 누르면 EffectBlockModal이 뜬다.
- 모달에서 값을 입력하고 삽입하면 해당 효과 카드의 generatedText가 바뀐다.
- 효과 카드에는 다음을 표시한다:
  1. 효과 번호
  2. 효과 종류
  3. 생성 결과 미리보기
  4. 경고 메시지
  5. 편집 버튼
  6. 확정 버튼
  7. 확정 해제 버튼
  8. 삭제 버튼
  9. 위로/아래로 이동 버튼

확정 처리:
- 확정 전에는 입력/편집 가능
- 확정 후에는 generatedText만 보여주고 입력 필드는 접기
- 확정 해제를 누르면 다시 편집 가능

효과 추가/제거:
- "효과 추가" 버튼을 누르면 새 빈 효과 카드 추가
- 삭제 버튼으로 기존 효과 카드 제거 가능
- 최소 1개 효과 카드는 유지해도 되고, 0개도 허용해도 됨

최종 스킬 신청 텍스트:
- effects 배열의 generatedText를 줄바꿈으로 합쳐서 출력한다.
- 출력 형식:

!스킬신청
이름: 혈인각
계통: 혈계
계열: 화력
랭크: B
계산식: d20 + 랭크 + 민첩
효과:
상태템플릿부여 대상 출혈 수치:5 횟수:3
스택증가 자신 혈인 +1 최대:10
조건: 대상에게 공격 적중 시
대가: 이면침식 +1
설명: 피를 새긴 발차기로 적을 찢고 혈인을 축적한다.

검증:
- 계산식에 대상상태_ 또는 대상스택_이 들어가면 "대상 지정 필요" 경고를 표시할 것.
- 상태/스택 참조 블럭은 프리뷰 계산에서 0으로 처리하거나 계산 불가로 표시해도 된다. 단, 오류가 아니라 "실제 사용 시 현재 상태/스택을 참조합니다"라고 설명할 것.
- 자유 입력 효과는 운영진 수동 검수 대상 경고.
- 상태 템플릿 부여에서 출혈인데 수치나 횟수가 없으면 경고.
- 구속인데 저항 설정이 없으면 저항 권장 경고.
- 스택 증가/설정인데 최대값이 없으면 최대값 권장 경고.

모바일 대응:
- 모달은 화면 중앙 또는 하단 시트 형태.
- max-height 적용.
- overflow-y-auto 적용.
- 입력칸은 w-full min-w-0.
- 버튼은 flex-wrap.
- 카드와 버튼이 겹치지 않게 할 것.

수정 후 npm run dev로 실행 오류가 없는지 확인해줘.
