이 프로젝트는 일반 캐릭터 빌더가 아니라, Aporia ORPG/TRPG 룰 전용 캐릭터 빌더야.
내가 아래에 룰 사양을 줄 테니, 먼저 이 내용을 docs/rules-spec.md에 정리하고, 그 다음 앱 구현에 사용해줘.

중요:
- 아래 사양에 없는 룰은 임의로 만들지 말 것.
- 데이터와 계산 로직은 src/data, src/utils로 분리할 것.
- UI는 모바일에서도 깨지지 않게 만들 것.
- 일단 실행 가능한 Vite + React + Tailwind 앱으로 만들 것.
- npm run dev로 Preview에서 확인 가능해야 함.

[기본 구조]
캐릭터는 스탯, 기능, 숙련, 스킬을 가진다.
성장예산 안에서 스탯/기능/숙련/스킬 비용을 소비한다.
사용점수 = 스탯 비용 합 + 기능 비용 합 + 숙련 비용 합 + 스킬 비용 합.
남은점수 = 현재 레벨 성장예산 - 사용점수.

[액션 계산]
액션 판정은 d20이 아니라 액션 계수 기반 d6 묶음이다.
계산 흐름:
1. 기초부 = 관련 스탯값 × 계수의 합
2. 배율부 = 1 + 관련 기능/숙련 수치 × 계수의 합
3. 최종계수 = 기초부 × 배율부
4. d6 개수 = ceil(최종계수 / 5), 최소 1d6
5. 기대값 = d6 개수 × 3.5

[스킬 메이커]
스킬 입력 항목:
이름, 계통, 계열, 랭크, 계산식, 효과, 조건, 대가, 설명

계통 선택지:
마술, 주술, 신성, 혈계, 요력, 초능력, 과학, 특수

계열 선택지:
화력, 방호, 치유, 재생, 간섭, 강화, 특수

계산식은 직접 입력 가능해야 하고, 버튼으로도 토큰을 추가할 수 있어야 한다.
계산식 버튼:
d20, 2d6, 랭크, 근력, 민첩, 내구, 감각, 지능, 스택_이름, 대상상태_상태_수치

계산식 프리뷰:
d20은 기대값 10.5
d6은 기대값 3.5
2d6은 기대값 7
랭크는 랭크 내부값으로 변환
스탯명은 현재 캐릭터 스탯 내부값으로 변환
스택_ 또는 대상상태_ 변수는 일단 프리뷰 계산에서는 0으로 처리하거나, 계산 불가 경고를 표시해도 된다.

계산식 검증:
허용 변수:
d20, d6, 2d6, 랭크, 근력, 민첩, 내구, 감각, 지능, 스택_로 시작하는 변수, 대상상태_로 시작하는 변수, 숫자, +, -, *, /, 괄호
그 외 토큰이 있으면 오류 경고 표시.

효과도 직접 입력 가능해야 하고, 버튼으로도 토큰을 추가할 수 있어야 한다.
효과 버튼:
상태템플릿부여 대상
상태템플릿부여 자신
스택증가 자신
스택증가 대상
수치:
횟수:
최대:
저항:가능
저항난이도:최종값

효과 검증:
상태/스택 효과인데 수치, 횟수, 최대값이 하나도 없으면 경고.
자동 처리 명령이 아니면 “운영진 수동 검수 대상” 경고.

[UI 요구사항]
왼쪽에는 캐릭터 입력과 스킬 메이커.
오른쪽에는 요약, 액션 상세, 액션 표, 신청 텍스트.
모바일에서는 1열로 쌓이게.
기능/숙련 UI는 이름, 소모점, - 숫자 + 조작부가 겹치지 않게.
버튼과 텍스트가 칸 밖으로 나가지 않게.
