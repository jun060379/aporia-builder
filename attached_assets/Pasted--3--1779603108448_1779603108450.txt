웹 빌더 3차 사용성 패치를 진행해줘.

중요:
- 현재 프로젝트의 기존 파일을 수정할 것.
- 파일 전체를 새 앱으로 갈아엎지 말 것.
- 기존 액션 계산, 포인트 계산, 스킬 계산 로직은 유지할 것.
- 이번 작업은 초보자 프리셋, 빌드 경고, 스킬 비용 포함 예상점수 표시가 목적이다.
- npm run dev에서 오류 없이 실행되게 할 것.

수정사항:

1. 캐릭터 빌더에 "초보자 프리셋" 섹션을 추가해줘.

프리셋은 버튼 또는 카드 형태로 제공한다.
프리셋 적용 시 이름, 종족, 빌드 기준 레벨, 이면침식은 유지하고,
스탯/기능/숙련만 프리셋 값으로 변경한다.

프리셋은 Lv1 성장예산 65 안에서 안전하게 들어가는 기본형으로 만들어줘.

공통 규칙:
- 모든 스탯 기본값은 E
- 주 스탯은 C
- 보조 스탯은 D
- 주 기능은 3
- 보조 기능은 1
- 주 숙련은 2
- 나머지 기능/숙련은 0

프리셋 목록:

주 스탯 근력 C, 보조 스탯 민첩 D
무기술 3, 기동술 1, 참격숙련 2

관통 기동형:
주 스탯 민첩 C, 보조 스탯 감각 D

타격 중장형:

무기술 3, 인내 1, 타격숙련 2

격투형:
주 스탯 근력 C, 보조 스탯 민첩 D
격투술 3, 기동술 1, 격투숙련 2

사격형:
주 스탯 감각 C, 보조 스탯 민첩 D
사격술 3, 관찰 1, 사격숙련 2

방어형:
주 스탯 내구 C, 보조 스탯 근력 D

회피형:
주 스탯 민첩 C, 보조 스탯 감각 D
기동술 3, 관찰 1, 회피숙련 2

저항형:
주 스탯 내구 C, 보조 스탯 지능 D
인내 3, 이면학 1, 저항숙련 2

조사형:

2. 프리셋 섹션에 안내문을 추가해줘.

문구:
"프리셋은 Lv1 기준으로 안전하게 시작할 수 있는 기본 배치입니다. 적용 후 세부 수치를 자유롭게 조정할 수 있습니다."

3. 요약 영역에 스킬 비용 포함 예상점수를 추가해줘.

현재 본체 사용점수는 유지한다.
추가로 현재 작성 중인 스킬의 비용을 반영한 예상치를 보여줘.

표시 항목:
- 본체 사용점수
- 현재 스킬 비용
- 스킬 포함 예상 사용점수
- 스킬 포함 예상 남은점수

계산:
현재 스킬 비용 = SKILL_COST[skill.rank]
스킬 포함 예상 사용점수 = 본체 사용점수 + 현재 스킬 비용
스킬 포함 예상 남은점수 = 성장예산 - 스킬 포함 예상 사용점수

단, 스킬 이름이 비어 있더라도 현재 선택 랭크의 비용을 보여줘도 된다.
표시 문구에 "현재 작성 중인 스킬 1개 기준"이라고 적어줘.

4. 신청 전 검수 또는 경고 영역에 빌드 위험 경고를 추가해줘.

경고 조건:

- 본체 사용점수가 성장예산을 초과하면:
"본체 사용점수가 성장예산을 초과했습니다."

- 스킬 포함 예상 사용점수가 성장예산을 초과하면:
"현재 작성 중인 스킬까지 승인될 경우 성장예산을 초과합니다."

- 이름이 비어 있으면:
"캐릭터 이름이 비어 있습니다."

- 최고 액션의 기대값이 15 미만이면:
"주력 액션이 낮습니다. 초보자라면 프리셋 사용을 권장합니다."

- 선택한 액션의 주 기능이나 주 숙련이 0이면:
"선택한 액션의 핵심 기능 또는 숙련이 낮습니다."

5. 위험 경고는 오류와 안내를 구분해서 표시해줘.

예:
- 예산 초과는 빨간 경고
- 프리셋 권장은 노란 안내
- 문제가 없으면 초록 안내

6. 프리셋 적용 후 액션 상세, 액션 표, 사용점수, 신청 텍스트가 즉시 갱신되게 해줘.

7. 모바일에서도 프리셋 카드가 깨지지 않게 해줘.
카드형 또는 버튼형 그리드로 표시하고, 작은 화면에서는 1열로 내려가게 해줘.

8. 기존 캐릭터 신청 텍스트 형식은 바꾸지 말 것.
경험치, 레벨, 일상점, 별명은 신청 텍스트에 다시 추가하지 말 것.
이면침식은 유지할 것.

9. 수정 후 npm run dev로 오류가 없는지 확인해줘.

10. 완료 후 변경 내용을 요약해줘.
