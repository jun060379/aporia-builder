웹 빌더 1차 동기화 패치를 진행해줘.

중요:
- 현재 프로젝트의 기존 파일을 수정할 것.
- 파일 전체를 새 앱으로 갈아엎지 말 것.
- 기존 포인트 계산, 액션 계산, 스킬 계산 로직은 가능한 한 유지할 것.
- 이번 패치는 UI/출력 형식/선택지 동기화 중심이다.
- npm run dev에서 오류 없이 실행되게 할 것.

수정사항:

1. 스킬 계통 목록을 다음으로 통일해줘.

마술 / 주술 / 신성 / 마법 / 혈계 / 요력 / 특수

기존 목록에 초능력, 과학이 있으면 제거하고, 마법이 없으면 추가해줘.

예:
const SYSTEMS = ["마술", "주술", "신성", "마법", "혈계", "요력", "특수"];

2. 캐릭터 빌더에서 일상점 직접 입력 항목을 제거해줘.

제거할 것:
- character 상태의 daily 또는 일상점 직접 입력 필드
- 기본 정보 UI의 일상점 입력칸
- 캐릭터 신청 텍스트의 `일상점:` 줄
- 신청 전 검수의 일상점 직접 입력 관련 항목

주의:
- 스킬 계산식 고급 변수로서의 `일상점`은 나중에 쓸 수 있으므로 금지하지 말 것.
- 캐릭터 빌딩/캐릭터 신청에서 직접 입력하지 않게만 할 것.

3. 이면침식은 유지해줘.

조건:
- 기본값은 0.
- 캐릭터 신청 텍스트에도 `이면침식:` 줄은 남길 것.
- 도움말에 다음 문구를 넣어줘.

"이면침식은 스킬 최종값 배율에 영향을 주며, 10에 도달하면 로스트 처리됩니다."

4. 캐릭터 신청 텍스트에서 `일상점:` 줄을 제거해줘.

5. 별명/호칭 입력칸이 있다면 제거하거나, 안내문만 남겨줘.

안내문:
"별명은 디스코드 서버 별명 기준으로 자동 등록됩니다."

캐릭터 신청 텍스트에는 `별명:` 항목을 넣지 말 것.

6. 스킬 신청 텍스트의 효과 출력 형식을 수정해줘.

현재처럼 한 줄로:
효과: 내용

이렇게 출력하지 말고, 아래처럼 출력되게 해줘.

효과:
효과줄1
효과줄2

효과가 없으면 다음 중 하나로 처리해도 된다.
- 효과:
  없음
- 효과:
  빈 줄

단, 효과 없음은 오류로 처리하지 말 것.
효과 항목은 선택 항목이다.

7. 액션을 카테고리별로 정리해서 보여줘.

카테고리:

피해 액션:
참격 / 관통 / 타격 / 격투 / 사격

대응 액션:
방어 / 회피 / 저항

탐색 액션:
조사 / 해석 / 은신 / 추적

사회 액션:
설득

액션 표나 액션 선택 UI에서 이 카테고리를 반영해줘.

8. 캐릭터 빌더의 액션 상세에 "계산식/계수 보기" 기능을 추가해줘.

중요:
- 참격만 하드코딩하지 말 것.
- 현재 코드의 ACTIONS 객체를 기준으로 모든 액션의 계산식이 자동 표시되게 만들 것.
- ACTIONS[name].b는 기초부 스탯 목록.
- ACTIONS[name].f는 기능 배율부 목록.
- ACTIONS[name].p는 숙련 배율부 목록.
- ACTIONS 객체의 계수는 임의로 바꾸지 말 것.

모든 액션에 적용되어야 한다:
참격, 관통, 타격, 격투, 사격,
회피, 방어, 저항,
조사, 해석, 은신, 추적, 설득.

9. 액션 계산식/계수 보기에는 다음 내용이 표시되어야 한다.

예시: 참격

기초부:
근력 × 1
민첩 × 0.5

배율부:
무기술 × 0.15
기동술 × 0.1
참격숙련 × 0.25

공식:
(근력 + 민첩 × 0.5) × (1 + 무기술 × 0.15 + 기동술 × 0.1 + 참격숙련 × 0.25)

현재 캐릭터 기준 계산:
근력 E(3) × 1 = 3
민첩 E(3) × 0.5 = 1.5
기초부 = 4.5

무기술 0 × 0.15 = 0
기동술 0 × 0.1 = 0
참격숙련 0 × 0.25 = 0
배율부 = 1

최종계수 = 4.5
d6 = ceil(4.5 / 5) = 1d6
기대값 = 3.5

이 구조가 모든 액션에서 자동으로 나오게 해줘.

10. 공식 문자열은 ACTIONS 객체를 읽어서 자동 생성해줘.

예:
ACTIONS["사격"]이면 자동으로

기초부:
감각 × 1
민첩 × 0.5

배율부:
사격술 × 0.15
관찰 × 0.1
사격숙련 × 0.25

공식:
(감각 + 민첩 × 0.5) × (1 + 사격술 × 0.15 + 관찰 × 0.1 + 사격숙련 × 0.25)

이렇게 나와야 한다.

11. 액션 공식/계수 보기 영역은 모바일에서도 깨지지 않게 해줘.

권장:
- 카드형
- 접기/펼치기
- 긴 공식은 줄바꿈
- overflow 방지
- 표보다 세로 카드 우선

12. 액션 계산식/계수 보기 영역에 짧은 도움말을 추가해줘.

문구:
"스탯은 기초부에 영향을 줍니다. 기능과 숙련은 배율부에 영향을 줍니다. 숙련은 특정 액션의 전문성을 가장 강하게 반영합니다."

13. 수정 후 npm run dev로 오류가 없는지 확인해줘.

14. 완료 후 변경 내용을 요약해줘.
