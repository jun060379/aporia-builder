현재 앱의 기능 로직은 만족스럽다.
이제 레이아웃과 시각 디자인만 개선해줘.

중요:
- 캐릭터 빌더, 포인트 계산, 액션 계산, 스킬 메이커 로직은 절대 바꾸지 말 것.
- 데이터 값, 비용표, 액션 공식, 신청 텍스트 형식도 바꾸지 말 것.
- UI/스타일/레이아웃만 수정할 것.
- npm run dev에서 오류 없이 실행되게 할 것.

디자인 방향:
이 앱은 신전기 ORPG의 캐릭터 빌더다.
분위기는 “오컬트 기관의 차가운 콘솔”이 아니라,
“일상과 비일상의 조화, 그 경계선에 선 캐릭터 등록지”에 가깝다.

핵심 키워드:
- 일상과 비일상의 경계
- 돌아갈 곳으로서의 일상
- 위험하지만 낭만적인 이면
- 세련되고 모던한 디자인
- 도시의 밤, 창가의 빛, 비 오는 골목, 푸른 새벽, 희미한 네온
- 아련함, 투명함, 약간의 쓸쓸함
- 하지만 정보는 명확하게 읽혀야 함

전체 스타일:
1. 너무 어둡고 딱딱한 해킹 콘솔처럼 만들지 말 것.
2. 완전한 검은색 배경보다는, 밝은 일상 영역과 어두운 이면 영역이 겹친 듯한 느낌으로.
3. 배경은 은은한 그라데이션을 사용.
   예:
   - slate-950 → indigo-950 → violet-950
   - 또는 밝은 카드와 어두운 배경의 대비
4. 카드에는 반투명 유리 느낌을 약하게 사용.
   예:
   - bg-white/80
   - dark:bg-slate-900/70
   - backdrop-blur
   - border-white/20
5. 너무 SF스럽거나 군사 단말 느낌은 피할 것.
6. 텍스트는 읽기 쉽게 유지.

색상 방향:
- 기본 배경: 깊은 남청, 보라빛 밤, 흐린 회색
- 일상 포인트: 따뜻한 아이보리, 연한 금색, 옅은 복숭아빛
- 비일상 포인트: 청록, 보라, 푸른빛
- 위험/침식: 붉은색보다는 장밋빛/자주빛 계열
- 정상/안정: 부드러운 녹색 또는 청록

추천 색감:
- 배경: bg-gradient-to-br from-slate-950 via-indigo-950 to-violet-950
- 카드: bg-white/85 또는 bg-slate-900/70
- 밝은 카드 사용 시: text-slate-900
- 어두운 카드 사용 시: text-slate-100
- 강조: text-cyan-300, text-violet-300, text-amber-200
- 경고: text-rose-300
- 성공: text-emerald-300

레이아웃 방향:
1. 상단 헤더는 “경계선” 느낌을 강조.
   제목:
   APORIA BUILDER
   부제:
   Everyday / Unreality Character Sheet

2. 헤더에는 짧은 문구를 넣어도 좋다.
   예:
   “돌아갈 일상이 있기에, 이면은 더욱 선명해진다.”

3. 왼쪽은 캐릭터를 만드는 “일상적 기록지” 느낌.
   - 기본 정보
   - 스탯
   - 기능
   - 숙련
   - 스킬 메이커

4. 오른쪽은 “이면 관측 패널” 느낌.
   - 요약
   - 액션 상세
   - 액션 표
   - 신청 텍스트

5. 데스크톱 xl 이상에서는 오른쪽 패널을 sticky로 만들어줘.
   예:
   xl:sticky xl:top-6

6. 모바일에서는 모든 섹션이 1열로 자연스럽게 쌓이게 해줘.

섹션 카드 디자인:
- 각 섹션은 너무 딱딱한 박스가 아니라, 기록지/유리 패널 느낌.
- 둥근 모서리 유지.
- 테두리는 얇고 은은하게.
- hover 효과는 과하지 않게.
- 섹션 제목 앞에 작은 번호나 라벨을 넣어도 좋음.
  예:
  01 기본 정보
  02 스탯
  03 기능
  04 숙련
  05 스킬 메이커

입력창 디자인:
- 너무 새까만 터미널 느낌은 피할 것.
- 입력창은 깨끗하고 모던하게.
- 밝은 카드 안에서는 흰색/연회색 입력창.
- 어두운 카드 안에서는 slate-950/70 입력창.
- focus 시 cyan/violet 계열 테두리.

기능/숙련 카드:
- 현재 구조를 유지하되, 더 부드럽고 보기 좋게.
- 이름, 소모점, - 숫자 + 조작부가 절대 겹치지 않게.
- 모바일에서도 카드 내부에서 자연스럽게 세로 배치.
- 소모점은 너무 강한 노란색보다 부드러운 amber/cream 계열.

스킬 메이커:
- 이 부분은 “비일상에 손을 뻗는 영역”처럼 보이게.
- 계산식 블럭, 효과 블럭, 경고 메시지가 명확히 구분되어야 함.
- 경고는 무섭게 빨간색만 쓰기보다, rose/amber 계열로 부드럽게.
- 확정된 효과 카드가 있다면 약간 빛나는 테두리나 은은한 배경을 줘도 좋음.

요약 카드:
- 성장예산, 사용점수, 남은점수, 최고 액션은 작은 대시보드 카드.
- 남은점수가 정상일 때는 청록/녹색.
- 초과일 때는 rose 계열.
- 최고 액션은 violet/cyan 계열로 강조.

액션 표:
- 데이터는 명확하게.
- 너무 해킹 콘솔처럼 만들지 말 것.
- 행 hover 시 은은하게 빛나는 느낌.
- 피해 액션 태그는 rose.
- 평가 태그 색상:
  기초/보통: slate
  어려움: cyan
  고난도: amber
  초월: violet
  예외적: rose

신청 텍스트:
- 복사용 영역이므로 가독성이 우선.
- 완전한 터미널 느낌보다는 “기록 로그” 느낌.
- font-mono는 유지.
- 배경은 slate-950 또는 semi-transparent dark.
- 글자는 cyan-50 또는 slate-100.
- border는 cyan/violet 계열로 은은하게.

추가 디테일:
- 배경에 아주 희미한 radial gradient를 넣어도 좋음.
  예:
  한쪽은 따뜻한 빛, 다른 한쪽은 푸른/보라빛.
- 일상과 비일상의 대비를 배경 색으로 표현.
  왼쪽은 약간 따뜻한 빛.
  오른쪽은 약간 차가운 빛.
- 애니메이션은 최소화.
  hover, focus, transition 정도만.

절대 하지 말 것:
- 군사/기관/해킹 콘솔처럼 너무 차갑게 만들지 말 것.
- 판타지 양피지 스타일로 만들지 말 것.
- 지나치게 네온사이버펑크처럼 만들지 말 것.
- 로직, 계산식, 데이터, 신청 텍스트 형식을 바꾸지 말 것.

수정 후 Preview에서 모바일/데스크톱 모두 확인하고, 변경한 디자인 요소를 요약해줘.
