현재 디자인이 너무 어둡다.
기능 로직은 건드리지 말고, 색감과 레이아웃 분위기만 다시 조정해줘.

목표:
"어두운 오컬트 콘솔"이 아니라
"일상과 비일상이 겹친 세련된 캐릭터 기록지" 느낌으로 바꿔줘.

핵심 방향:
1. 전체 배경을 너무 어둡게 하지 말 것.
2. 기본 카드와 입력 영역은 밝은 톤을 사용.
3. 비일상 느낌은 배경 그라데이션, 포인트 컬러, 그림자, 테두리로만 은은하게 표현.
4. 정보 가독성을 최우선으로 유지.

색감 방향:
- 배경:
  밝은 새벽빛, 흐린 도시 하늘, 옅은 아이보리, 연한 청회색
  예:
  bg-gradient-to-br from-slate-50 via-indigo-50 to-violet-100

- 카드:
  흰색 또는 반투명 흰색
  예:
  bg-white/85
  border-white/70
  shadow-lg
  backdrop-blur

- 주요 텍스트:
  text-slate-900

- 보조 텍스트:
  text-slate-500 또는 text-slate-600

- 비일상 포인트:
  violet-500
  cyan-500
  indigo-500

- 따뜻한 일상 포인트:
  amber-200
  rose-100
  peach 계열 느낌

- 위험/침식:
  새빨간색보다 rose-500, fuchsia-500 계열

디자인 컨셉:
낮과 밤의 경계.
돌아갈 일상이 있는 밝은 기록지.
그러나 카드 테두리와 배경 그림자에 이면의 보라빛/푸른빛이 희미하게 비치는 느낌.

헤더:
- 완전 검은 헤더를 쓰지 말 것.
- 밝은 유리 패널 또는 옅은 그라데이션 카드로 바꿔줘.
- 제목은 진한 slate 색.
- 포인트로 violet/cyan gradient text를 사용해도 좋음.

예시:
APORIA BUILDER
Everyday / Unreality Character Sheet

문구:
돌아갈 일상이 있기에,
이면은 더욱 선명해진다.

섹션 카드:
- 흰색/반투명 흰색 카드
- 둥근 모서리
- 부드러운 그림자
- 은은한 보라/청록 테두리
- 너무 어두운 bg-slate-900 계열은 사용하지 말 것

입력창:
- 밝은 배경
- 흰색 또는 slate-50
- border-slate-200
- focus 시 violet-400 또는 cyan-400
- 글자는 slate-900

버튼:
- 기본 버튼은 밝은 카드 위에 어울리게
- 주요 버튼은 indigo/violet 계열
- 복사 버튼은 slate-800 정도만 사용 가능
- 너무 검은 버튼을 남발하지 말 것

요약 카드:
- 밝은 카드 유지
- 남은점수 정상: emerald-100 / emerald-700
- 초과: rose-100 / rose-700
- 최고 액션: violet-100 / violet-700

액션 표:
- 흰색 또는 slate-50 기반
- 헤더는 indigo-50 또는 violet-50
- hover는 violet-50 정도로 은은하게
- 피해 태그는 rose-100 / rose-600

신청 텍스트:
- 완전 검은 터미널 대신 "기록 로그" 느낌.
- 배경은 slate-900 정도는 가능하지만, 너무 크고 무겁게 보이면 안 됨.
- 또는 bg-slate-800 text-slate-100 정도로 완화.
- 주변 카드가 밝으니 textarea만 어둡게 해서 대비를 주는 것은 허용.

배경 디테일:
- 화면 한쪽에는 따뜻한 빛 느낌의 radial gradient
- 다른 한쪽에는 푸른/보라빛 radial gradient
- 하지만 전체는 밝은 새벽/흐린 도시 느낌이어야 함

절대 하지 말 것:
- 전체 배경을 검정/남색으로 덮지 말 것
- 군사 콘솔/해킹 콘솔처럼 만들지 말 것
- 너무 네온사이버펑크처럼 만들지 말 것
- 기능 로직, 데이터, 계산식, 신청 텍스트 형식은 바꾸지 말 것

수정 후 Preview에서 확인하고, 전체 화면이 이전보다 밝아졌는지 확인해줘.
