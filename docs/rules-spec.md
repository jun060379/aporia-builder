## 액션 계산

액션 판정은 d20이 아니라 액션 계수 기반 d6 묶음이다.

### 계산 흐름

1. **기초부** = 관련 스탯값 × 계수의 합
2. **배율부** = 1 + 관련 기능/숙련 수치 × 계수의 합
3. **최종계수** = 기초부 × 배율부
4. **d6 개수** = ceil(최종계수 / 5), 최소 1d6
5. **기대값** = d6 개수 × 3.5

## 스킬 메이커

### 입력 항목

이름, 계통, 계열, 랭크, 계산식, 효과, 조건, 대가, 설명

### 계통 선택지

마술, 주술, 신성, 혈계, 요력, 초능력, 과학, 특수

### 계열 선택지

화력, 방호, 치유, 재생, 간섭, 강화, 특수

### 계산식

- 직접 입력 가능
- 버튼으로 토큰 추가 가능: `d20`, `2d6`, `랭크`, `근력`, `민첩`, `내구`, `감각`, `지능`, `스택_이름`, `대상상태_상태_수치`

#### 계산식 프리뷰

- d20 → 기대값 10.5
- d6 → 기대값 3.5
- 2d6 → 기대값 7
- 랭크 → 랭크 내부값으로 변환
- 스탯명 → 현재 캐릭터 스탯 내부값으로 변환
- 스택_, 대상상태_ 변수 → 0으로 처리하거나 계산 불가 경고

#### 계산식 검증

허용 변수: `d20`, `d6`, `2d6`, `랭크`, `근력`, `민첩`, `내구`, `감각`, `지능`, `스택_*`, `대상상태_*`, 숫자, `+`, `-`, `*`, `/`, 괄호
그 외 토큰이 있으면 오류 경고.

### 효과

- 직접 입력 가능
- 버튼으로 토큰 추가: `상태템플릿부여 대상`, `상태템플릿부여 자신`, `스택증가 자신`, `스택증가 대상`, `수치:`, `횟수:`, `최대:`, `저항:가능`, `저항난이도:최종값`

#### 효과 검증

- 상태/스택 효과인데 수치, 횟수, 최대값이 하나도 없으면 경고
- 자동 처리 명령(`상태템플릿부여`, `스택증가`)이 아니면 "운영진 수동 검수 대상" 경고
